## while loop
- read asks the user to enter something.
- "if" checks if the user entered "q".
- If the user enters "q", "break" stops the loop.
- If the user enters something that is not a number, it shows an error message.
- "continue" tells the loop to start again.
- If the user enters a number, it prints the number.
- After that, the loop starts again and asks for another number.
- The loop continues until the user enters "q"
